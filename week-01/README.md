# W1 — 자바스크립트를 실행하는 두 곳

**주제**: VS Code, Node.js, 브라우저 콘솔, 실행 환경의 차이

## 학습목표

자바스크립트는 브라우저에서도 돌고 Node에서도 돕니다. 문법이 같으니 같은 언어지만,
쓸 수 있는 도구는 서로 다릅니다. 이번 주에 그 경계를 직접 확인해두면, 다음 주부터
문법을 익힐 때 어디서 코드를 돌려야 할지 고민하지 않게 됩니다.

- VS Code로 저장소 폴더를 열고, 편집기 안의 터미널에서 명령을 실행할 수 있다.
- Node.js를 설치하고, 설치 확인을 넘어 `.js` 파일을 직접 실행할 수 있다.
- 같은 코드를 Node와 브라우저 양쪽에서 실행해, 결과가 같은지 다른지 확인할 수 있다.
- `console.log`로 값을 출력하고, 개발자도구 Console 탭에서 그 결과를 읽을 수 있다.
- `document`나 `window`처럼 브라우저에만 있는 것, `require`나 `process`처럼 Node에만 있는 것을 구분할 수 있다.
- 한쪽에서만 나는 에러 메시지를 읽고, 무엇이 없어서 나는 에러인지 말할 수 있다.
- 문법만 공부할 때 Node로 실행하는 편이 편한 이유를 자기 말로 설명할 수 있다. (W2부터 실제로 그렇게 합니다)

---

## 과제: 같은 코드, 두 곳에서 돌려보기

### 요구사항

- [ ] VS Code로 작업 환경 만들기
  - 저장소 폴더를 VS Code로 열기 (파일 하나가 아니라 폴더를 열 것)
  - 편집기 안에서 터미널 열기 (`Ctrl` + `` ` ``)
  - 그 터미널에서 `git status`를 실행해 W0에서 쓰던 터미널과 같은 자리인지 확인
- [ ] Node.js 설치하고 실제로 실행하기
  - LTS 버전 설치 후 `node -v`로 확인
  - `week-01/hello.js`를 만들어 `console.log`로 'hello! javascript!' 문자열 및 값을 몇 개 자유롭게 출력 (숫자·문자열·계산식)
  - 이번 주에는 값을 코드에 그대로 적습니다. 값에 이름을 붙이는 일은 다음 주에 다룹니다
  - 터미널에서 `node week-01/hello.js`로 실행하고, 실행 화면을 캡쳐하여 첨부
  - `node`만 입력해 REPL에 들어가 계산식을 몇 개 쳐보고 `.exit`으로 빠져나오기
- [ ] 같은 파일을 브라우저에서 실행하기
  - `week-01/index.html`을 만들고 `<script src="hello.js"></script>`로 방금 그 파일을 불러오기
  - 브라우저로 열어 개발자도구 Console 탭에서 출력 확인 (`F12`)
  - Console에 출력된 화면을 캡쳐하여 첨부
- [ ] 두 환경의 차이를 확인하고 `week-01/notes.md` 파일을 만들어 자유롭게 기록하기
  - 양쪽에서 똑같이 동작하는 코드 하나
  - 브라우저에서만 되는 코드 하나 (`document.title`, `window` 등)
  - Node에서만 되는 코드 하나 (`process.version`, `require` 등)
  - 각각을 반대쪽에서도 실행해보고, 나온 **에러 메시지를 원문 그대로** 옮겨 적기
  - 문법만 공부할 때 Node가 편한 이유를 한 문단으로 정리

### 제약

- 개발자도구는 Console 탭만 사용
  - Elements·Network·Sources는 실제로 필요해지는 주차에서 다룹니다
- 출력은 `console.log`만 사용. `alert` 금지
  - `alert`는 코드 실행을 멈춰 세웁니다. 값을 여러 개 찍어보기에도 불편합니다
- 예제 코드는 복사하지 말고 직접 입력할 것
  - 오타로 나는 에러를 이번 주에 몇 번 만나두는 편이 낫습니다
- 에러가 나면 지우지 말고 기록할 것
  - 에러 메시지는 실패 통보가 아니라 어디가 문제인지 알려주는 정보입니다
- 현재 실행 환경에 이미 node가 설치되어 있을 수 있습니다
  - 따로 설치 여부를 검사하지는 않겠습니다. 현재 설치된 NODE를 그대로 사용해도 됩니다.
  - 단, 반드시 별도 PC에서 설치하는 과정을 경험해 보세요

### 완료 기준

- 같은 `.js` 파일 하나가 Node와 브라우저 양쪽에서 실행된 캡처가 각각 있음
- `notes.md`에 한쪽에서만 나는 에러 두 가지가 메시지 원문과 함께 기록되어 있음
- 그 에러가 각각 무엇이 없어서 나는 것인지 설명이 붙어 있음
- 문법 학습에 Node를 쓰는 이유가 자기 말로 정리되어 있음
