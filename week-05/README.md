# W5 — 반복문

**주제**: `for`, `while`, `break`/`continue`, 누적 변수

## 학습목표

지금까지 쓴 코드는 위에서 아래로 한 번 흐르고 끝났습니다. 이번 주부터는 **같은 코드를
여러 번 돌립니다.**

처음 배우는 사람이 반복문에서 자주 틀리는 곳은 세 군데입니다. **누적 변수를 어디에
선언하는가**, **몇 번 도는가**, **언제 멈추는가**입니다. 세 군데 다 한 번씩 틀려보는 게 이번 주 과제입니다.
특히 무한 루프는 일부러 만들어봐야 합니다. 처음 만났을 때 당황하지 않으려면요.

- `for`의 세 부분(초기화 · 조건 · 증감)이 각각 언제 실행되는지 설명할 수 있다.
- 같은 반복을 `for`와 `while`로 각각 쓰고, 상황에 맞는 쪽을 고를 수 있다.
- 누적 변수를 반복문 바깥에 선언해야 하는 이유를 설명할 수 있다.
- 누적 변수의 초기값을 무엇으로 둘지 상황에 맞게 정할 수 있다.
- 반복 횟수가 하나 모자라거나 하나 넘치는 실수를 스스로 찾아낼 수 있다.
- `break`와 `continue`를 구분해 쓸 수 있다.
- 무한 루프를 만들어보고, 왜 멈추지 않았는지 짚어낼 수 있다.
- 문자열을 한 글자씩 훑을 수 있다.

> 한 가지 주제가 90분 넘게 막히면 질문하세요. 30분쯤 막히면 `week-05/읽으면진다-5주차치트노트.md`를 보셔도 됩니다.
> 단, **1단계를 직접 해본 뒤에** 펴세요.

---

## 과제: 반복문 익히고, 값 쌓고, 멈춰 세우기

### 1단계 — 반복문 익히기

`week-05/playground.js`를 만들어 아래를 직접 돌려봅니다.
관찰한 것은 `week-05/notes.md`에 적습니다.

- [ ] `for`의 세 부분이 각각 몇 번 실행되는지 세어보기
  - 세 자리에 각각 다른 문구를 출력하게 만들기. 예를 들면 이런 모양입니다

    ```js
    for (let i = 1; console.log('조건 검사', i), i <= 3; console.log('증감 전'), i++) {
      console.log('  블록 실행', i);
    }
    ```

  - 위 코드가 어렵게 느껴지면 초기화 자리 대신 반복문 앞에 `console.log('초기화')`를 두고
    조건과 증감만 위 방식으로 확인해도 됩니다
  - **`notes.md`에 적을 것**: 블록이 3번 실행될 때 조건 검사는 몇 번 실행됐는지, 그리고 왜 그런지
- [ ] 반복 횟수를 네 가지로 바꿔 출력 개수 세기
  - `i = 0; i < 5` / `i = 1; i <= 5` / `i = 1; i < 5` / `i = 0; i <= 5`
  - 각각 몇 개가 출력되는지 세어 `notes.md`에 표로 적기
  - **`notes.md`에 적을 것**: `0`에서 시작할 때와 `1`에서 시작할 때 조건에 `<`와 `<=` 중 무엇을 짝지어야 같은 횟수가 되는지
- [ ] 1부터 5까지 출력하는 코드를 `for`와 `while`로 각각 쓰기
  - **`notes.md`에 적을 것**: `for`의 초기화·조건·증감이 `while` 버전에서 각각 몇 번째 줄로 갔는지
- [ ] **무한 루프를 일부러 만들고** `Ctrl+C`로 멈추기
  - `while` 버전에서 `i++` 한 줄만 지우면 됩니다
  - 출력이 멈추지 않는 것을 확인한 뒤 `Ctrl+C`
  - **`notes.md`에 적을 것**: 무엇을 지웠더니 안 멈췄는지, 그리고 `Ctrl+C`를 눌렀을 때 터미널에 무엇이 나왔는지
- [ ] `break`와 `continue`를 같은 반복문에 각각 넣어 비교하기
  - 1부터 10까지 도는 반복문에서 `i === 5`일 때 `break`한 경우와 `continue`한 경우를 각각 실행
  - **`notes.md`에 적을 것**: 두 경우에 출력된 숫자를 그대로 나열하고, 무엇이 다른지 한 문장

### 2단계 — 값 쌓기

- [ ] 1부터 100까지의 합을 `for`로 구하기 (답은 `5050`)
  - 먼저 **누적 변수를 반복문 블록 안에** 선언해서 실행해보기
  - 결과가 `5050`이 아닐 겁니다. 그 결과를 그대로 `notes.md`에 적기
  - 그다음 선언을 반복문 바깥으로 옮겨 다시 실행
  - **`notes.md`에 적을 것**: 두 결과와, 안에 선언했을 때 왜 그 값이 나왔는지 한 문단
- [ ] 같은 합계를 `while`로 다시 구해 `5050`이 나오는지 확인하기
  - **`notes.md`에 적을 것**: 이 문제에 `for`와 `while` 중 무엇이 더 어울린다고 보는지, 그 판단 기준
- [ ] 구구단 한 단을 골라 `3 x 1 = 3`부터 `3 x 9 = 27`까지 아홉 줄 출력하기
- [ ] 1부터 50까지 중 3의 배수만 출력하되, 30을 넘으면 `break`로 멈추기
  - 3의 배수를 걸러내는 방법을 **두 가지로** 써보기: `continue`를 쓰는 방법과 `if` 블록으로 감싸는 방법
  - **`notes.md`에 적을 것**: 두 코드를 나란히 붙이고, 어느 쪽이 읽기 쉬운지와 그 이유

### 3단계 — 문자열 훑기

- [ ] 문자열 하나를 정해 `length`를 출력하고, 첫 글자와 마지막 글자를 각각 꺼내기
  - 마지막 글자를 꺼낼 때 `문자열[문자열.length]`를 **먼저** 시도해볼 것
  - **`notes.md`에 적을 것**: `문자열[문자열.length]`가 무엇을 냈는지, 마지막 글자를 꺼내려면 어떻게 해야 했는지
- [ ] 반복문으로 한 글자씩 전부 출력하기
- [ ] 그 문자열에 특정 글자가 몇 번 나오는지 세기
  - 누적 변수 하나와 반복문 하나면 됩니다
  - 실제로 들어 있는 글자로 한 번, **들어 있지 않은 글자로도 한 번** 세어볼 것
  - **`notes.md`에 적을 것**: 두 경우의 결과. 없는 글자를 셌을 때 에러가 났는지 아니면 어떤 값이 나왔는지

### 제약

- 반복 횟수를 손으로 펼쳐 쓰지 말 것
  - `console.log`를 100줄 쓰면 답은 나오지만 배우는 게 없습니다
- 배열 메서드와 `for...of` 사용 금지. `for`와 `while`만
  - 배열은 다음 주 주제입니다. 지금은 반복 그 자체에만 집중합니다
- 누적 변수는 `let`으로 선언할 것
  - `const`로는 안 됩니다. 왜 안 되는지는 W2에서 봤습니다
- 무한 루프는 반드시 한 번 만들어볼 것
  - 나중에 실수로 만났을 때 "아 이거구나" 하고 `Ctrl+C`를 누를 수 있어야 합니다
- **함수를 쓰지 마세요.** (W4와 같은 규칙)
- `var` 금지, 의미 없는 변수 이름 금지

### 완료 기준

`notes.md`만 읽고도 아래에 답할 수 있으면 통과입니다.

- 최종 코드가 에러 없이 실행되고, 1부터 100까지의 합이 `5050`으로 나옴
- **블록이 3번 실행될 때 조건 검사가 몇 번 실행되는지**와 그 이유가 적혀 있음
- 네 가지 반복 조건의 출력 개수가 표로 정리되어 있음
- **누적 변수를 블록 안에 선언했을 때 나온 값**과, 왜 그 값이 나왔는지가 적혀 있음
- 무한 루프를 만들려고 지운 줄이 무엇인지 적혀 있음
- `break`와 `continue`를 각각 넣었을 때 출력된 숫자가 나열되어 있음
- 3의 배수 걸러내기를 두 방식으로 쓴 코드가 나란히 있고, 어느 쪽이 읽기 쉬운지 판단이 적혀 있음
- `문자열[문자열.length]`의 결과와, 마지막 글자를 꺼내는 방법이 적혀 있음
- 글자 세기 결과가 맞고, 없는 글자를 셌을 때의 값도 적혀 있음
- `for`와 `while`을 고르는 자기 기준이 한 문장으로 적혀 있음
