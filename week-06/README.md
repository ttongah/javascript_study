# W6 — 배열 기초

**주제**: 배열 선언, 인덱스, `length`, 요소 추가·제거, 반복문으로 훑기

## 학습목표

지금까지는 값 하나에 이름 하나를 붙였습니다. 그런데 주문 항목이 열 개라면 변수를 열 개
만들 수는 없습니다. **값을 줄 세워 담는 그릇**이 배열입니다.

W5에서 익힌 반복문을 여기서 본격적으로 씁니다. 반복문과 배열은 짝입니다.
그리고 이번 주에는 **인덱스를 하나 어긋나게 세는 실수**를 반드시 한 번 겪게 될 겁니다.
겪고 넘어가야 합니다.

- 배열을 만들고, 인덱스로 요소를 읽고 바꿀 수 있다.
- 인덱스가 `0`부터 시작한다는 것을 코드로 확인하고, 마지막 요소에 접근할 수 있다.
- `length`가 무엇을 세는지 알고, 마지막 인덱스와 어떻게 다른지 설명할 수 있다.
- 없는 인덱스에 접근하면 무엇이 나오는지 확인하고 설명할 수 있다.
- `push` · `pop` · `unshift` · `shift`로 요소를 넣고 뺄 수 있다.
- 반복문으로 배열 전체를 훑으며 합계 · 평균 · 최댓값을 구할 수 있다.
- 누적 변수의 초기값을 잘못 잡으면 어떤 입력에서 틀리는지 예를 들 수 있다.
- 배열 안에 배열이 든 구조를 이중 반복문으로 훑을 수 있다.

> 한 가지 주제가 90분 넘게 막히면 질문하세요. 30분쯤 막히면 `week-06/읽으면진다-6주차치트노트.md`를 보셔도 됩니다.
> 단, **1단계를 직접 해본 뒤에** 펴세요.

## 과제: 배열 만들고, 훑고, 집계하기

### 1단계 — 배열 만들고 읽기

`week-06/playground.js`를 만들어 아래를 직접 돌려봅니다.
관찰한 것은 `week-06/notes.md`에 적습니다.

아래 배열을 기준으로 진행하세요.

```js
const 점수 = [80, 95, 70, 88];
```

- [ ] 배열을 통째로 출력하고, `점수[0]`과 `점수[1]`을 각각 출력하기
  - **`notes.md`에 적을 것**: 첫 번째 요소의 인덱스가 몇 번인지
- [ ] `점수[1] = 100;`으로 값을 바꾼 뒤 배열을 다시 출력하기
  - **`notes.md`에 적을 것**: `const`로 선언했는데 왜 에러가 나지 않았는지 지금 생각하는 이유 한 문장
    (정답은 몇 주 뒤에 다룹니다. 지금 생각을 그대로 남겨두세요)
- [ ] `점수.length`를 출력한 뒤, 아래 세 가지를 각각 출력해 비교하기
  - `점수[점수.length]`
  - `점수[점수.length - 1]`
  - `점수[3]`
  - **`notes.md`에 적을 것**: 셋의 결과와, 마지막 요소를 꺼내려면 무엇을 써야 하는지
- [ ] `점수[99]`를 출력해보기
  - **`notes.md`에 적을 것**: 에러가 났는지 아니면 어떤 값이 나왔는지. W2에서 본 값 중 하나입니다
- [ ] `typeof 점수`를 출력해보기
  - **`notes.md`에 적을 것**: 나온 값. 예상과 다를 겁니다. 이유는 지금 찾지 말고 결과만 남기세요

### 2단계 — 넣고 빼기

- [ ] `push('A')` → `pop()` → `unshift('B')` → `shift()` 순서로 하나씩 실행하기
  - **매 단계마다** 배열 전체와 `length`를 함께 출력할 것
  - **`notes.md`에 적을 것**: 아래 표를 채우기

    | 메서드 | 어느 쪽 끝을 건드리나 | 실행 후 length |
    |---|---|---|
    | `push` | | |
    | `pop` | | |
    | `unshift` | | |
    | `shift` | | |

- [ ] `pop()`과 `shift()`의 반환값을 변수에 담아 출력하기
  - **`notes.md`에 적을 것**: 두 메서드가 각각 무엇을 돌려주는지
- [ ] `push()`의 반환값도 변수에 담아 출력하기
  - **`notes.md`에 적을 것**: `pop`이 돌려주는 것과 종류가 다릅니다. 무엇을 돌려주는지
- [ ] 빈 배열 `const 빈배열 = [];`에서 `pop()`을 실행하기
  - **`notes.md`에 적을 것**: 에러가 났는지, 어떤 값이 나왔는지

### 3단계 — 반복문으로 집계하기

`const 점수 = [80, 95, 70, 88];`을 대상으로 합니다. 손으로 계산한 값은 합계 `333`, 평균 `83.25`, 최댓값 `95`입니다.

- [ ] 반복문으로 **합계**를 구해 `333`이 나오는지 확인하기
- [ ] **평균**을 구해 `83.25`가 나오는지 확인하기
  - 나누는 수에 `4`를 손으로 적지 말고 `점수.length`를 쓸 것
  - 배열에 값을 하나 더 넣어 다시 실행해, 평균이 저절로 따라오는지 확인
- [ ] **최댓값**을 찾되, 누적 변수 초기값을 `0`으로 두고 먼저 해보기
  - `[80, 95, 70, 88]`로는 `95`가 잘 나옵니다
  - 이제 같은 코드에 `[-5, -2, -9]`를 넣어 실행하기
  - **`notes.md`에 적을 것**: 나온 값과, 그 값이 배열 안에 있는지 여부
  - 초기값을 바꿔 고친 뒤 두 배열 모두 맞는지 확인
  - **`notes.md`에 적을 것**: 초기값을 무엇으로 바꿨는지와 그 이유
- [ ] 빈 배열 `[]`로 합계 · 평균 · 최댓값을 각각 실행하기
  - **`notes.md`에 적을 것**: 세 결과를 그대로 적기. 하나는 `NaN`이 나올 겁니다

### 4단계 — 배열 안의 배열

아래 배열을 기준으로 진행하세요. **반마다 인원이 다릅니다.**

```js
const 반별점수 = [[80, 90], [70, 100, 60], [85]];
```

- [ ] `반별점수.length`와 `반별점수[1].length`를 각각 출력하기
  - **`notes.md`에 적을 것**: 두 값이 각각 무엇을 세는지
- [ ] `반별점수[1][2]`를 출력해 어떤 값이 나오는지 확인하기
- [ ] 이중 반복문으로 여섯 개 점수를 전부 출력하기
  - 안쪽 반복문의 조건을 **일부러 `반별점수.length`로** 써서 먼저 실행해볼 것
  - **`notes.md`에 적을 것**: 그때 출력에 무엇이 섞여 나왔는지, 그리고 조건을 무엇으로 고쳤는지
- [ ] 전체 합계(`485`)와 전체 점수 개수(`6`)를 구하기
  - 개수는 `반별점수.length`가 아닙니다. 왜 아닌지 생각해보고 구할 것

### 제약

- 배열 고차 메서드 금지 (`map` `filter` `reduce` `forEach` 등)
  - 그 메서드가 무엇을 대신해주는지 알려면 손으로 먼저 해봐야 합니다. 다다음 주에 같은 계산을 다시 씁니다
- `Math.max` · `Math.min` 금지. 직접 비교해서 찾을 것
  - 최댓값을 찾는 절차 자체가 이번 주 학습 내용입니다
- `for...of` 사용 금지. 인덱스를 쓰는 `for`나 `while`만
  - 인덱스를 직접 다뤄봐야 `0`부터 시작한다는 감각이 생깁니다
- **함수를 쓰지 마세요.** (W4·W5와 같은 규칙)
- `var` 금지, 의미 없는 변수 이름 금지

### 완료 기준

`notes.md`만 읽고도 아래에 답할 수 있으면 통과입니다.

- `playground.js`가 에러 없이 실행되고, 합계 `333` · 평균 `83.25` · 최댓값 `95`가 나옴
- **`점수[점수.length]` · `점수[점수.length - 1]` · `점수[3]`의 결과**가 각각 적혀 있음
- `점수[99]`의 결과가 적혀 있음
- `typeof 점수`의 결과가 적혀 있음
- 네 메서드 표(어느 쪽 끝 / 실행 후 length)가 채워져 있고, `pop`과 `push`의 반환값 차이가 적혀 있음
- 빈 배열에서 `pop()`을 했을 때의 결과가 적혀 있음
- **초기값 `0`으로 `[-5, -2, -9]`를 돌렸을 때 나온 값**과, 초기값을 무엇으로 어떻게 고쳤는지가 적혀 있음
- 빈 배열로 돌린 합계 · 평균 · 최댓값 세 결과가 적혀 있음
- **안쪽 조건을 `반별점수.length`로 썼을 때** 출력에 무엇이 섞였는지가 적혀 있음
- 전체 합계 `485`와 전체 개수 `6`이 나옴
