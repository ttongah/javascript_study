## 배열은 값을 줄 세워 담습니다

```js
const 과목 = ['국어', '영어', '수학'];
const 점수 = [80, 95, 70, 88];
```

각 자리에는 **번호(인덱스)** 가 붙습니다. 그리고 그 번호는 `0`부터 시작합니다.

```
과목:  [ '국어', '영어', '수학' ]
인덱스:    0       1       2
```

```js
과목[0]    // '국어'
과목[2]    // '수학'
과목[1] = '과학';   // 바꾸기도 됩니다
```

`const`로 선언했는데 왜 바뀌냐고 물을 수 있습니다. W2에서 봤듯 `const`가 막는 건
**그 이름이 다른 값을 가리키는 것**이지 내용물이 아닙니다. 이 이야기는 뒤에서 제대로 다룹니다.

## `length`와 마지막 인덱스

`length`는 **개수**입니다. 인덱스는 `0`부터 시작하니, 마지막 인덱스는 언제나 `length - 1`입니다.

```js
const 점수 = [80, 95, 70, 88];
점수.length              // 4
점수[점수.length]        // undefined  ← 없는 자리
점수[점수.length - 1]    // 88         ← 마지막
```

여기서 하나 어긋나는 실수를 흔히 합니다. 반복문 조건도 마찬가지입니다.

```js
for (let i = 0; i < 점수.length; i++)     // 0,1,2,3 → 맞음
for (let i = 0; i <= 점수.length; i++)    // 0,1,2,3,4 → 마지막에 undefined
```

`0`에서 시작하면 `<`입니다. W5에서 본 것과 같은 짝입니다.

## 없는 인덱스에 접근하면

에러가 나지 않습니다. `undefined`가 나옵니다.

```js
점수[99]    // undefined
```

이게 편하면서도 위험합니다. 오타로 인덱스를 잘못 써도 프로그램이 멈추지 않고
`undefined`인 채로 계속 실행됩니다. 그러다 그 값으로 계산을 하면 `NaN`이 나오는데
그때는 원인이 한참 앞줄에 있어서 찾기 성가십니다.

`typeof 점수`를 찍어보면 `'object'`가 나옵니다. 배열인데 `'array'`가 아닙니다.
지금은 그렇구나 하고 넘어가세요. 이유는 객체를 다루는 주차에서 봅니다.

## 넣고 빼기

| 메서드 | 하는 일 | 어느 쪽 끝 | 돌려주는 값 |
|---|---|---|---|
| `push(값)` | 넣기 | 뒤 | 바뀐 뒤의 `length` |
| `pop()` | 빼기 | 뒤 | 빠진 그 값 |
| `unshift(값)` | 넣기 | 앞 | 바뀐 뒤의 `length` |
| `shift()` | 빼기 | 앞 | 빠진 그 값 |

이름이 헷갈리면 앞뒤로 나눠 외우는 편이 낫습니다. `push`/`pop`은 뒤, `shift`/`unshift`는 앞.

```js
const 대기줄 = ['A', 'B'];
대기줄.push('C');        // ['A', 'B', 'C']
const 나간사람 = 대기줄.shift();   // 'A'가 빠지고 대기줄은 ['B', 'C']
```

**빈 배열에서 `pop`이나 `shift`를 하면** 에러가 아니라 `undefined`가 나옵니다.
없는 인덱스를 읽었을 때와 같습니다.

이 네 메서드는 **원본 배열을 바꿉니다.** 새 배열을 돌려주는 게 아닙니다.
그래서 `const`로 선언해도 동작합니다.

## 반복문으로 집계하기

배열과 반복문은 짝입니다. W5에서 익힌 그대로에 인덱스만 붙이면 됩니다.

```js
let 합계 = 0;
for (let i = 0; i < 점수.length; i++) {
  합계 += 점수[i];
}
const 평균 = 합계 / 점수.length;
```

나누는 수를 `4`라고 손으로 적지 마세요. 배열에 값을 하나 더 넣는 순간 틀립니다.
`length`를 쓰면 저절로 따라옵니다.

> **여기부터는 3단계 최댓값 항목의 답에 가깝습니다.** 초기값 `0`으로 음수 배열을 한 번 돌려본 뒤에 읽으세요.

## 최댓값 초기값 함정

이번 주에서 가장 배울 게 많은 자리입니다.

```js
let 최댓값 = 0;                          // 여기가 문제
for (let i = 0; i < 점수.length; i++) {
  if (점수[i] > 최댓값) {
    최댓값 = 점수[i];
  }
}
```

점수가 전부 양수면 잘 돌아갑니다. 그런데 `[-5, -2, -9]`를 넣으면 **`0`이 나옵니다.**
배열에 없는 값입니다. `0`보다 큰 게 하나도 없어서 초기값이 그대로 남은 겁니다.

고치는 방법은 **첫 번째 요소를 초기값으로 삼는 것**입니다.

```js
let 최댓값 = 점수[0];
for (let i = 1; i < 점수.length; i++) {   // 1부터 시작
  if (점수[i] > 최댓값) {
    최댓값 = 점수[i];
  }
}
```

배열 안에 실제로 있는 값에서 출발하니 어떤 숫자가 들어와도 안전합니다.
반복을 `1`부터 시작하는 것도 자연스럽습니다. 0번은 이미 초기값으로 썼으니까요.

**빈 배열이면** 이 코드는 `undefined`를 냅니다. 합계는 `0`, 평균은 `NaN`이 나옵니다.
"값이 없을 때 무엇을 돌려줘야 하는가"는 정답이 하나가 아닙니다. 지금은 그런 경우가
있다는 걸 확인해두는 것으로 충분합니다.

## 배열 안의 배열

배열 요소가 다시 배열일 수 있습니다.

```js
const 반별점수 = [[80, 90], [70, 100, 60], [85]];

반별점수.length        // 3   ← 반이 세 개
반별점수[1]            // [70, 100, 60]
반별점수[1][2]         // 60  ← 두 번째 반의 세 번째 점수
```

대괄호를 두 번 씁니다. 첫 번째가 바깥 인덱스, 두 번째가 안쪽 인덱스입니다.

훑을 때는 반복문을 두 겹으로 씁니다.

```js
for (let i = 0; i < 반별점수.length; i++) {
  for (let j = 0; j < 반별점수[i].length; j++) {
    console.log(반별점수[i][j]);
  }
}
```

안쪽 조건에 주의하세요. `반별점수.length`가 아니라 **`반별점수[i].length`** 입니다.
반마다 인원이 다르니까요. 바깥 길이를 그대로 쓰면 어떤 반에서는 `undefined`가 나오고
어떤 반은 덜 훑습니다.

변수 이름도 `i`, `j`보다 `반`, `학생`처럼 붙이면 이 실수가 눈에 잘 띕니다.
